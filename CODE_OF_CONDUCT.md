# Poki Code of Conduct

[English](#poki-community-rules) | [简体中文](#poki-社区规则) | [繁體中文](#poki-社群規則) | [日本語](#poki-コミュニティのルール) | [한국어](#poki-커뮤니티-규칙) | [Español](#normas-de-la-comunidad-de-poki)

This code applies to the Poki repository and to the Poki tester groups (WeChat, Discord and any other group run for Poki). It has two parts. The short Poki rules come first, in six languages. They say how we work together day to day and how moderation works in the tester groups. The full [Contributor Covenant 3.0](#contributor-covenant-30) follows, in English, and is the binding text. Where the two differ, the Covenant wins, and the Poki rules add to it.

## Poki community rules

**How we talk**
- Critique the work, not the person.
- Comparisons with other projects are welcome when they are specific.
- Do not state a cause before it is confirmed. Say what you saw, and mark a guess as a guess.
- After three rounds back and forth on one point, move the discussion to a GitHub issue.

**Report on GitHub first**
- Testers are expected to be able to file GitHub issues. Open one before raising a problem in a group, so it is tracked and not lost in the chat. Then link it in the group.

**Not acceptable**
- Labels and name-calling, mockery, pile-ons, telling people to leave, and harassment.
- Sharing someone's personal information or private messages without their consent.

**Maintainers and admins**
- Maintainers and group admins are held to a higher standard.
- An admin who is part of a dispute steps aside from moderating it.

**Steps**
- Pause, reminder, warning, a 7-day time out, removal.
- A time out or a removal needs two admins. The person can appeal after 14 days.

**Reporting**
- In a tester group, message an admin who is not part of the dispute.
- On GitHub, open an issue whose title starts with "Conduct", and leave out personal details. For something that should stay private, ask a maintainer in an issue for a private channel first.
- Security vulnerabilities go to [GitHub private vulnerability reporting](https://github.com/JosssphZhou/poki/security/advisories/new). Conduct reports do not.

## Poki 社区规则

**交流方式**
- 评论作品，不评论人。
- 欢迎与其他项目比较，但要具体。
- 原因确认之前不要下结论。说出你看到的现象，猜测请标明是猜测。
- 同一个问题来回三轮以后，请转到 GitHub issue 里继续讨论。

**先在 GitHub 上报告**
- 测试者需要会提交 GitHub issue。在群里提出问题之前先开一个 issue，这样问题会被跟踪，不会淹没在聊天里。然后把链接发到群里。

**不可接受的行为**
- 贴标签和骂人、嘲讽、群起围攻、让别人离开，以及骚扰。
- 未经同意分享他人的个人信息或私信。

**维护者和管理员**
- 对维护者和群管理员的要求更高。
- 身为争议一方的管理员，不参与这次争议的管理。

**处理步骤**
- 暂停、提醒、警告、禁言 7 天、移出。
- 禁言或移出需要两位管理员同意。当事人可在 14 天后申诉。

**举报**
- 在测试群里，私信一位不涉及争议的管理员。
- 在 GitHub 上，开一个标题以 “Conduct” 开头的 issue，不要写个人信息。需要保密的情况，请先在 issue 里请维护者提供私下沟通的渠道。
- 安全漏洞请通过 [GitHub 私密漏洞报告](https://github.com/JosssphZhou/poki/security/advisories/new) 提交。行为举报不走这个渠道。

## Poki 社群規則

**交流方式**
- 評論作品，不評論人。
- 歡迎與其他專案比較，但要具體。
- 原因確認之前不要下結論。說出你看到的現象，猜測請標明是猜測。
- 同一個問題來回三輪以後，請轉到 GitHub issue 裡繼續討論。

**先在 GitHub 上回報**
- 測試者需要會提交 GitHub issue。在群組裡提出問題之前先開一個 issue，這樣問題會被追蹤，不會淹沒在聊天裡。然後把連結貼到群組裡。

**不可接受的行為**
- 貼標籤和罵人、嘲諷、群起圍攻、要別人離開，以及騷擾。
- 未經同意分享他人的個人資料或私訊。

**維護者和管理員**
- 對維護者和群組管理員的要求更高。
- 身為爭議一方的管理員，不參與這次爭議的管理。

**處理步驟**
- 暫停、提醒、警告、禁言 7 天、移出。
- 禁言或移出需要兩位管理員同意。當事人可在 14 天後申訴。

**檢舉**
- 在測試群組裡，私訊一位不涉及爭議的管理員。
- 在 GitHub 上，開一個標題以 “Conduct” 開頭的 issue，不要寫個人資料。需要保密的情況，請先在 issue 裡請維護者提供私下溝通的管道。
- 安全漏洞請透過 [GitHub 私密漏洞回報](https://github.com/JosssphZhou/poki/security/advisories/new) 提交。行為檢舉不走這個管道。

## Poki コミュニティのルール

**話し方**
- 批評するのは作品で、人ではありません。
- 他のプロジェクトとの比較は、具体的であれば歓迎します。
- 原因が確かめられる前に断定しないでください。見たことを伝え、推測は推測だと書いてください。
- 同じ点について三往復したら、議論を GitHub の issue に移してください。

**まず GitHub で報告**
- テスターには GitHub で issue を作れることを期待しています。グループで問題を挙げる前に issue を作り、チャットに埋もれず追跡されるようにしてから、グループにリンクを貼ってください。

**認められない行為**
- レッテル貼りや悪口、嘲笑、集団での攻撃、出て行けと言うこと、嫌がらせ。
- 本人の同意なく個人情報や個人宛てのメッセージを共有すること。

**メンテナーと管理者**
- メンテナーとグループ管理者には、より高い基準が求められます。
- 争いの当事者である管理者は、その件のモデレーションから外れます。

**対応の段階**
- 中断、注意、警告、7 日間の発言停止、退出。
- 発言停止や退出には管理者二人の同意が必要です。本人は 14 日後に異議を申し立てられます。

**報告の方法**
- テスターグループでは、争いに関わっていない管理者に個別に連絡してください。
- GitHub では、タイトルが “Conduct” で始まる issue を作り、個人情報は書かないでください。非公開にすべき内容は、まず issue でメンテナーに非公開の連絡手段を尋ねてください。
- セキュリティの脆弱性は [GitHub のプライベート脆弱性報告](https://github.com/JosssphZhou/poki/security/advisories/new) へ。行動に関する報告はそちらではありません。

## Poki 커뮤니티 규칙

**대화 방식**
- 사람이 아니라 작업을 비평합니다.
- 다른 프로젝트와의 비교는 구체적이라면 환영합니다.
- 원인이 확인되기 전에 단정하지 마세요. 본 것을 말하고, 추측은 추측이라고 밝혀 주세요.
- 한 가지 문제로 세 번 주고받았다면 논의를 GitHub 이슈로 옮겨 주세요.

**먼저 GitHub에 보고하기**
- 테스터는 GitHub 이슈를 작성할 수 있어야 합니다. 그룹에서 문제를 꺼내기 전에 이슈를 먼저 열어 채팅에 묻히지 않고 추적되게 한 뒤, 그룹에 링크를 공유해 주세요.

**허용되지 않는 행동**
- 낙인찍기와 욕설, 조롱, 집단 공격, 나가라고 말하기, 괴롭힘.
- 동의 없이 다른 사람의 개인정보나 개인 메시지를 공유하는 것.

**메인테이너와 관리자**
- 메인테이너와 그룹 관리자에게는 더 높은 기준이 적용됩니다.
- 분쟁 당사자인 관리자는 그 분쟁의 중재에서 빠집니다.

**조치 단계**
- 일시 중단, 안내, 경고, 7일 활동 정지, 내보내기.
- 활동 정지나 내보내기에는 관리자 두 명의 동의가 필요합니다. 당사자는 14일 후 이의를 제기할 수 있습니다.

**신고 방법**
- 테스터 그룹에서는 분쟁에 관여하지 않은 관리자에게 개인 메시지를 보내 주세요.
- GitHub에서는 제목이 “Conduct”로 시작하는 이슈를 열고 개인정보는 적지 마세요. 비공개로 다뤄야 할 내용이라면 먼저 이슈에서 메인테이너에게 비공개 연락 방법을 요청해 주세요.
- 보안 취약점은 [GitHub 비공개 취약점 보고](https://github.com/JosssphZhou/poki/security/advisories/new)로 보내 주세요. 행동 신고는 그곳으로 보내지 않습니다.

## Normas de la comunidad de Poki

**Cómo hablamos**
- Critica el trabajo, no a la persona.
- Las comparaciones con otros proyectos son bienvenidas cuando son concretas.
- No afirmes una causa antes de confirmarla. Cuenta lo que viste y marca una suposición como suposición.
- Tras tres rondas sobre un mismo punto, lleva la conversación a un issue de GitHub.

**Primero en GitHub**
- Se espera que quienes prueban Poki sepan abrir issues en GitHub. Abre uno antes de plantear un problema en un grupo, para que quede registrado y no se pierda en el chat, y después enlázalo en el grupo.

**No es aceptable**
- Etiquetar e insultar, burlarse, atacar en grupo, decirle a alguien que se vaya y acosar.
- Compartir información personal o mensajes privados de alguien sin su consentimiento.

**Mantenedores y administradores**
- A los mantenedores y administradores de grupo se les exige más.
- Un administrador que forma parte de una disputa no la modera.

**Pasos**
- Pausa, recordatorio, advertencia, suspensión de 7 días, expulsión.
- Una suspensión o una expulsión requiere a dos administradores. La persona puede apelar pasados 14 días.

**Cómo informar**
- En un grupo de pruebas, escribe en privado a un administrador que no forme parte de la disputa.
- En GitHub, abre un issue cuyo título empiece por “Conduct”, sin datos personales. Si debe tratarse en privado, pide primero en un issue a un mantenedor un canal privado.
- Las vulnerabilidades de seguridad van al [informe privado de vulnerabilidades de GitHub](https://github.com/JosssphZhou/poki/security/advisories/new). Los informes de conducta no.

## Contributor Covenant 3.0

### Our Pledge

We pledge to make our community welcoming, safe, and equitable for all.

We are committed to fostering an environment that respects and promotes the dignity, rights, and contributions of all individuals, regardless of characteristics including race, ethnicity, caste, color, age, physical characteristics, neurodiversity, disability, sex or gender, gender identity or expression, sexual orientation, language, philosophy or religion, national or social origin, socio-economic position, level of education, or other status. The same privileges of participation are extended to everyone who participates in good faith and in accordance with this Covenant.


### Encouraged Behaviors

While acknowledging differences in social norms, we all strive to meet our community's expectations for positive behavior. We also understand that our words and actions may be interpreted differently than we intend based on culture, background, or native language.

With these considerations in mind, we agree to behave mindfully toward each other and act in ways that center our shared values, including:

1. Respecting the **purpose of our community**, our activities, and our ways of gathering.
2. Engaging **kindly and honestly** with others.
3. Respecting **different viewpoints** and experiences.
4. **Taking responsibility** for our actions and contributions.
5. Gracefully giving and accepting **constructive feedback**.
6. Committing to **repairing harm** when it occurs.
7. Behaving in other ways that promote and sustain the **well-being of our community**.


### Restricted Behaviors

We agree to restrict the following behaviors in our community. Instances, threats, and promotion of these behaviors are violations of this Code of Conduct.

1. **Harassment.** Violating explicitly expressed boundaries or engaging in unnecessary personal attention after any clear request to stop.
2. **Character attacks.** Making insulting, demeaning, or pejorative comments directed at a community member or group of people.
3. **Stereotyping or discrimination.** Characterizing anyone’s personality or behavior on the basis of immutable identities or traits.
4. **Sexualization.** Behaving in a way that would generally be considered inappropriately intimate in the context or purpose of the community.
5. **Violating confidentiality**. Sharing or acting on someone's personal or private information without their permission.
6. **Endangerment.** Causing, encouraging, or threatening violence or other harm toward any person or group.
7. Behaving in other ways that **threaten the well-being** of our community.

#### Other Restrictions

1. **Misleading identity.** Impersonating someone else for any reason, or pretending to be someone else to evade enforcement actions.
2. **Failing to credit sources.** Not properly crediting the sources of content you contribute.
3. **Promotional materials**. Sharing marketing or other commercial content in a way that is outside the norms of the community.
4. **Irresponsible communication.** Failing to responsibly present content which includes, links or describes any other restricted behaviors.


### Reporting an Issue

Tensions can occur between community members even when they are trying their best to collaborate. Not every conflict represents a code of conduct violation, and this Code of Conduct reinforces encouraged behaviors and norms that can help avoid conflicts and minimize harm.

When an incident does occur, it is important to report it promptly. To report a possible violation, see Reporting in the [Poki community rules](#poki-community-rules) above. Maintainers will keep the reporter's identity confidential.

Community Moderators take reports of violations seriously and will make every effort to respond in a timely manner. They will investigate all reports of code of conduct violations, reviewing messages, logs, and recordings, or interviewing witnesses and other participants. Community Moderators will keep investigation and enforcement actions as transparent as possible while prioritizing safety and confidentiality. In order to honor these values, enforcement actions are carried out in private with the involved parties, but communicating to the whole community may be part of a mutually agreed upon resolution.


### Addressing and Repairing Harm

If an investigation by the Community Moderators finds that this Code of Conduct has been violated, the following enforcement ladder may be used to determine how best to repair harm, based on the incident's impact on the individuals involved and the community as a whole. Depending on the severity of a violation, lower rungs on the ladder may be skipped.

1) Warning
   1) Event: A violation involving a single incident or series of incidents.
   2) Consequence: A private, written warning from the Community Moderators.
   3) Repair: Examples of repair include a private written apology, acknowledgement of responsibility, and seeking clarification on expectations.
2) Temporarily Limited Activities
   1) Event: A repeated incidence of a violation that previously resulted in a warning, or the first incidence of a more serious violation.
   2) Consequence: A private, written warning with a time-limited cooldown period designed to underscore the seriousness of the situation and give the community members involved time to process the incident. The cooldown period may be limited to particular communication channels or interactions with particular community members.
   3) Repair: Examples of repair may include making an apology, using the cooldown period to reflect on actions and impact, and being thoughtful about re-entering community spaces after the period is over.
3) Temporary Suspension
   1) Event: A pattern of repeated violation which the Community Moderators have tried to address with warnings, or a single serious violation.
   2) Consequence: A private written warning with conditions for return from suspension. In general, temporary suspensions give the person being suspended time to reflect upon their behavior and possible corrective actions.
   3) Repair: Examples of repair include respecting the spirit of the suspension, meeting the specified conditions for return, and being thoughtful about how to reintegrate with the community when the suspension is lifted.
4) Permanent Ban
   1) Event: A pattern of repeated code of conduct violations that other steps on the ladder have failed to resolve, or a violation so serious that the Community Moderators determine there is no way to keep the community safe with this person as a member.
   2) Consequence: Access to all community spaces, tools, and communication channels is removed. In general, permanent bans should be rarely used, should have strong reasoning behind them, and should only be resorted to if working through other remedies has failed to change the behavior.
   3) Repair: There is no possible repair in cases of this severity.

This enforcement ladder is intended as a guideline. It does not limit the ability of Community Managers to use their discretion and judgment, in keeping with the best interests of our community.


### Scope

This Code of Conduct applies within all community spaces, and also applies when an individual is officially representing the community in public or other spaces. Examples of representing our community include using an official email address, posting via an official social media account, or acting as an appointed representative at an online or offline event.
