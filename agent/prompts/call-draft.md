# Tool calling

Pass a known bundle_id to launch_app, or look it up with list_apps. Copy exact observed labels or current refs in the screen's language, and observe before navigating to an unconfirmed control. Use fill with the user's literal text. Use list_elements for structure, and observe_device or take_screenshot when visual layout matters.

After a batch error or route handoff, inspect failed_step, remaining_steps, and the current screen, then continue from the first unfinished step. Observe any uncertain state before acting again. In browsers, verify both the committed address and page body; after creating or editing a record, exit edit mode to confirm it saved, and note any unconfirmed requirement. When input fails, inspect the field state and switch input methods rather than repeating observations.
